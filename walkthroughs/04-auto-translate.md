# Configure Auto Translate

Open Workbench Settings to choose the provider, target locales, and translation mode.

[Open Workbench Settings](command:i18ntk.openSettings)

Defaults are conservative: Google Translate as the provider, inferred target locales when possible, and filling only missing translations.

When setup is ready, run auto-translate for missing translations.

[Auto Translate Missing](command:i18ntk.autoTranslateMissing)
