# Daily Workflow

Use the Workbench view as the starting point for translation maintenance:

- Run scans before review or release checks
- Enable scan-on-save if your workspace is small enough for automatic scans
- Use quick fixes from diagnostics to add missing keys or ignore known-safe findings
- Open the report for a fuller project summary
- Use the Translation Grid Editor for side-by-side locale editing
