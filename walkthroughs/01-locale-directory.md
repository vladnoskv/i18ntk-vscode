# Set the Locale Directory

i18ntk works best after it knows which folder contains your locale JSON files.

Use auto-detection first when your project uses a common folder name such as `locales`, `locale`, `i18n`, `translations`, `public/locales`, or `src/locales`.

[Detect and Scan](command:i18ntk.detectLocaleDirectory?%5B%7B%22rescan%22%3Atrue%7D%5D)

If your project stores translations somewhere else, select that folder directly.

[Choose Folder and Scan](command:i18ntk.chooseLocaleDirectory?%5B%7B%22rescan%22%3Atrue%7D%5D)
